### Google Analytics ID — что это и зачем

**Что это:** бесплатный идентификатор счётчика **Google Analytics 4 (GA4)**. Выглядит как `G-XXXXXXXXXX` (Measurement ID).

**Зачем:** чтобы видеть статистику сайта после запуска — сколько человек зашло, какие товары смотрят, сколько раз добавили в корзину и перешли в WhatsApp. Без этого ID аналитика на сайте не подключается.

**Что будет видно:** просмотры страниц, добавления в корзину, переходы в WhatsApp, заявки Sell/Trade (в связке с настройкой сайта).

**Кто создаёт:** рекомендуется **Заказчик** — сервис бесплатный, аккаунт остаётся у владельца магазина. По договорённости может создать Исполнитель с передачей доступа.

**Как получить (кратко):**
1. Зайти на [analytics.google.com](https://analytics.google.com) под Google-аккаунтом Заказчика
2. Создать property для `solovyev.store` → поток данных **Web**
3. Скопировать **Measurement ID** (`G-...`) и отправить Исполнителю



Задержка с материалами сдвигает срок запуска.

### Instagram auto-import — что входит

- Подключение Instagram API (access token от Заказчика)

- Автоимпорт новых постов: фото, подпись → черновик товара в админке

- Настройка cron-синхронизации (по расписанию)

- Краткая инструкция по использованию



*Подходит, если дропы публикуются в Instagram и нужно меньше ручной заливки на сайт.*



### CRM: каталог + заказы + заявки — что входит



Единый модуль: **удобная админка** + **Google Таблица** для учёта и резервной копии.



**В админ-панели `/admin`**

- Список заказов из WhatsApp checkout (фильтры, поиск, дата)

- Список заявок Sell/Trade с деталями и фото

- Статусы: новый / в работе / закрыт / отменён

- Карточка заказа / заявки — всё на одном экране

- Базовая статистика за период



**В Google Sheets (автосинхронизация)**

- Лист **«Каталог»** — синк товаров с сайтом (название, цена, размеры, статус)

- Лист **«Заказы»** — WhatsApp checkout (дата, SS-*, товар, размер, цена, ссылка)

- Лист **«Заявки»** — Sell/Trade (контакт, описание, фото, статус)



- Краткая инструкция по работе с админкой и таблицей



*Подходит для ежедневной работы в админке и параллельного учёта / отчётов в Google Sheets.*



### Онлайн-оплата (PayPlus / Cardcom) — что входит

Альтернатива Stripe для Израиля: приём карт в **₪**, выплаты на **израильский банк**. Stripe напрямую для израильского бизнеса не подключается.

**Кастомный checkout (€399 → €199 launch)**
- Интеграция PayPlus или Cardcom
- Корзина → оплата картой → страницы success / cancel
- Тестовый режим + запуск на проде
- Оформление оплаты в UI сайта (API), без «чужой» страницы
- Кнопки и flow в стиле SOLOVYEV STORE
- Webhook от платёжки, статус оплаты в админке
- Лог заказов с оплатой (в связке с CRM-модулем — по желанию)
- Bit / Apple Pay — если включены в тарифе провайдера

**Не входит (на стороне Заказчика):**
- Договор с PayPlus / Cardcom / Tranzila, merchant account, terminal
- עוסק מורשה, банковский счёт, комиссии шлюза (~1.5–3.5% + абонплата)
- חשבונית מס / интеграция с бухгалтерией

*Рекомендуется после запуска сайта с WhatsApp checkout.*



### Личные кабинеты — что входит

**Кабинет владельца** уже входит в пакет «Запуск» — это админ-панель `/admin` (каталог, настройки, FAQ). Отдельно не оплачивается.

**ЛК покупателя (€600 → €300 launch)**
- Регистрация и вход (email)
- Профиль: имя, телефон, адрес доставки
- История заказов (из CRM / WhatsApp checkout; при подключении оплаты — из платёжки)
- Избранное (по согласованию)

**ЛК сдатчика / consignment (€900 → €450 launch)**
- Личный кабинет для тех, кто сдаёт вещи на продажу
- Список вещей, статусы (на продаже / продано / выплачено)
- Сумма к выплате, история сделок
- Связка с Sell/Trade и админкой владельца

**Бандл: ЛК покупателя + ЛК сдатчика (€1 600 → €800 launch)** — оба модуля со скидкой.

*Рекомендуется после запуска основного сайта. Без модуля CRM или онлайн-оплаты часть данных в ЛК заполняется вручную или из WhatsApp.*
